## 工具与维护边界

Node 22.23.3 与 pnpm 12.11.2 属于开发环境，不打包二进制；其项目许可证均为 MIT（Node 包含其第三方声明）。gitleaks 使用 MIT 许可证，CI 固定官方版本并校验 SHA256。GitHub Actions 的固定版本/commit 见工作流。

直接包选自仍在维护的主流项目；使用稳定版不代表所有传递依赖都是最新。当前 Lighthouse CI 的工具链仍包含 glob 7、inflight、旧 rimraf 和 uuid 8 等弃用传递包；它们只用于本地/CI，不作为页面外链脚本。应随工具链升级复核，不做未经测试的强行覆盖。

## Optional font authoring tools

FontTools4.65.0 (MIT) and Brotli1.2.0 (MIT) are pinned in `scripts/font-subset-requirements.txt` for optional isolated regeneration. They are not included in the 651 npm package groups above and are not required by ordinary Node builds. The shipped font subsets retain OFL-1.1 notices; source/output hashes and exact-glyph verification are documented in `scripts/font-subset-README.md`.
