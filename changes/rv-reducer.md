# RV reducer page (L3)

Adds Chinese and English RV reducer lessons using the shared disassembly template, with 13 selectable component groups, three coupled stage views, axial explosion, orbit/reset controls and explicit 1/60 animation time scaling. Integer tooth edits automatically validate and rebuild the geometry and ratio; invalid combinations preserve the previous valid model. Input speed spans 0 to 3000 rpm and output speed is input divided by the coupled reduction ratio (121:1 by default).

The geometry uses 30-degree involute spur profiles with simplified radial roots and paired offset cycloidal profiles, three twin-eccentric cranks, fixed pins, output flanges, bearings and seals. Model assumptions and primary principle references are visible on the page. This is a generic rigid-body schematic, not manufacturing geometry or a force, stress, lubrication or life simulation.

A compressed named GLB and actual rendered responsive WebP images are included. Interactive rebuilds use the same generator as the offline model. Reduced-motion and low-resource modes avoid Three/GLB loading while keeping complete component selection and local calculations; the static image is explicitly identified as the default geometry.

Scoped Playwright contracts cover the bilingual controls, live valid/invalid rebuilds, speed/playback behavior, static fallbacks and ten same-document Home/page round trips with actual WebGL context disposal. Final executed verification evidence is supplied separately by the task coordinator.
