# Integrated robot joint page (L5)

Adds Chinese and English generic hollow robot-joint lessons through the existing shared disassembly page and lifecycle. Fourteen semantic parts carry bilingual names and localized role, feature and placeholder-material descriptions in Content Collections. Full-module and internal-mechanism views, manual exploded separation, real mesh selection, part labels and keyboard controls share one selected part. The internal view hides only the housing and front/rear covers. There is no transmission animation or operating-performance calculation.

An accessible SVG functional diagram distinguishes electrical power, mechanical torque, encoder feedback and brake control using line styles and a text legend. Native keyboard-operable buttons in the SVG select corresponding modeled parts. Either stator or rotor highlights the motor node. The external DC supply is explicitly unmodeled and selects the driver-board input boundary. Non-flow structural, bearing and thermal parts leave the diagram neutral and show an explicit context explanation. The spring-applied, electrically released brake describes holding after a controlled stop, without a safety-rating or emergency-stop claim.

Reduced-motion, low-resource and failed-WebGL modes retain all part selection, functional-flow selection and manual separation. A lightweight layer SVG follows separation, selection and view mode while the actual model-rendered poster retains its default exploded geometry. The heavy viewer is loaded only through the shared controller when 3D is appropriate. Canvas picks update the same flow and selected-part state as part tags and SVG nodes. Route disposal uses shared lifecycle cancellation and the viewer cleanup contract.

The source is an original teaching topology rather than a vendor replica. The thermal interface lies between the stator outside diameter and housing inside wall; the center conduit is stationary and distinct from the rotating input and output sleeves. The model omits cables, seals, fasteners and detailed circuit or contact behavior. Page-specific typography, diagrams and styles remain scoped to this page; no shared production template, P2, documentation or version changes are required. Executed model, browser, accessibility and performance evidence is supplied separately by the task coordinator.
