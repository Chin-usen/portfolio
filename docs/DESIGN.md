# 设计规范（v0.2）

- 状态：方向已确认（2026-10-14），选定 D1 极简科技 · 浅色。
- 2026-10-16：导航改为 N1（各板块独立页面，右上角切换），自 v1.3.0 起实现；深色页面背景改为 #0E0E10。

## 视觉方向
- 参照苹果产品页的极简科技风：大量留白、一屏只讲一件事、居中大标题、单一主视觉（功率模块 3D 渲染）。
- 浅色为主，关键数据段使用纯黑区块（位于作品页顶部）。
- 不使用框线、标注、网格等装饰元素。

## 文案原则
- 工程化、严谨，不使用营销话术。
- 标题直接写案例名称（例："芯片结温仿真"、"INPC 三电平功率模块"），副标题写对象与方法。
- 数据写清对象、单位与前后值（例："24 → 14 nH，Long Loop Inductance"）。
- 仿真卡片写明输入与输出。

## 导航与页面结构（N1）
- 每个板块是独立页面，通过顶栏右上角按钮切换，不把所有板块堆在首页一路下滑。路由：`/`、`/work`、`/work/[slug]`、`/lab`、`/lab/[slug]`、`/about`，英文版前缀 `/en`。
- 顶栏 52 px，毛玻璃，sticky。桌面（≥ 768 px）：左侧姓名链接首页；右侧分段按钮"作品 / 实验台 / 关于 | EN"。当前板块高亮（浅色底 #E8E8ED、深色底 #2C2C2E），并设 `aria-current="page"`；子页高亮所属板块，首页无高亮。
- 手机（< 768 px）：右上角 EN + 44×44 菜单按钮，展开为全屏菜单；当前项旁橙点（强调色）；Esc 关闭、焦点限制在菜单内、关闭后焦点回到按钮。
- 首页只有首屏（100svh，不滚动）：职位行、两行标题、方向、"查看作品 / 进入实验台"、主视觉、一行页脚。
- "联系"并入"关于"页底部（`#contact`），旧 `/contact` 重定向过去。
- 切页用 View Transitions（淡入 + 轻微位移，顶栏不动；减少动态效果时关闭），不引入动画库。切页后焦点移到新页面的 h1。
- 示意稿：`docs/design/N1-*`。
