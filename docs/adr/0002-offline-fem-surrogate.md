# ADR 0002：仿真采用"离线 FEM 抽样 + 网页代理模型"

- 状态：已接受（2026-10-14）

## 背景
仿真 case 有约 12 个连续变量，浏览器内实时有限元在移动端不可行；全因子网格扫描组合数过大。

## 决策
1. 线性导热下 Tj = T_cool + P·Rth，功率与冷却液温度在网页端精确计算，不参与抽样。
2. 其余几何与材料参数用拉丁超立方抽样，离线做 300–500 次 FEM 求解。
3. 拟合代理模型（标量输出用多项式/高斯过程/小型网络；温度场用 POD 降阶基）。
4. 页面显示代理模型相对 FEM 的验证误差，并用解析热阻网络交叉验证趋势。
5. 求解器只用开源软件，脚本与结果数据入库可复现。

## 后果
网页端为微秒级求值，移动端可用；新增 case 需离线重算与重新拟合。
