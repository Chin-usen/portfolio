# 内容与保密规范

本仓库公开。任何进入仓库的内容都视为已公开。

## 1. 永不入库

- 电话号码、出生日期、住址、身份证件信息。
- 前雇主及现雇主的客户名称、项目代号、内部报告、未提交专利、设备检测逻辑。
- 未经本人确认可公开的任何数值。
- 简历母版、事实素材库、原始照片（含 EXIF）。私人素材只放在仓库外，或放在已被 `.gitignore` 排除的 `private/`。

## 2. 可公开数值的规则

- 仅使用本人确认可公开的数值；受限数值只写区间或上界（例如"低于某值"）。
- 成果必须归属于正确的项目，不得混用。

## 3. Lab 内容规则

- 所有 3D 模型与仿真几何均为按公开原理、教科书与通用规格书风格重新绘制的通用结构，不复刻任何雇主产品。
- 功率模块类模型公开前须由本人确认"与工作中的设计无相似之处"。
- 每个 Lab 案例注明依据与简化假设；仿真注明求解器、网格、抽样数量与代理模型验证误差。
- Lab 统一标注 "Self-initiated"，与 Work 职业案例分开。

## 4. 自动检查

CI 运行敏感信息扫描（电话号码模式、日期模式、禁用关键词列表）。禁用关键词列表保存在仓库外的私有配置中，CI 通过加密变量读取。
