选中零件

叠层母排 Laminated busbar

作用
连接直流端子与上下桥臂芯片，承载主功率电流；P、N 两层构成换流回路。
特点
P、N 层面对面叠放、电流方向相反，磁场相互抵消，回路电感低；层间距越小、重叠越宽，电感越低。
常用材料
无氧铜 C1020（可镀镍/镀锡）；层间绝缘 PI 或 PEN 薄膜，边缘封压。
电路拓扑 · 与模型联动
母排回路电感（平行板近似）L ≈ μ₀·l·d / w

1.57 nH

忽略边缘效应、端子与芯片内部电感，仅用于比较趋势。
