## P 与冷却液温度的精确关系

固定几何、导热系数与换热系数 h，离散方程为：

```text
A T = (P / 100 W) f_100 + h T_cool b
A 1 = h b
T(P, T_cool) = T_cool 1 + (P / 100 W) T(100 W, 0)
```

`b` 是底面 Robin 积分权重；导热矩阵作用于常数场为零。因此峰值、面积平均温度、每个界面及有效场点对 P 线性，对 T_cool 平移；所有热阻不依赖 P/T_cool。这里的“精确”指模型方程，浮点计算仍存在舍入。

`scripts/audit_v2.py` 重新组装 24,897 节点、21,648 六面体的真实 FEM 系统，分别在默认参数、留出集中 Rjmax 最小和最大的参数下，直接改变热流和 Robin 环境温度求解，每组 5 个场景，共 15 次边界载荷验证。最大节点温度偏差 **3.68346e-11 °C**；最大相对代数残差 **1.62848e-12**。此步骤没有重算或改写 500 组训练数据。

浏览器评估器另以全部 100 个留出参数检查 8 组载荷：`(P,T_cool)=(0,25),(0,85),(25,0),(100,0),(300,0),(25,25),(100,65),(300,85)`。

| 验证对象 | 实际结果 |
| --- | --- |
| 峰值/平均热阻、对流分量、7 层热阻 | P/T_cool 改变后的差值严格为 0 |
| 峰值、平均、温度边界及所有层界面 | 仿射关系最大偏差 1.13687e-13 °C |
| 6,553,600 个场值比较 | 最大偏差 4.57764e-5 °C，符合 Float32 输出舍入容差 |
| 零功率 | 结温、层界面及全部场值严格等于 T_cool |
| 网格坐标与材料掩膜 | 不随 P/T_cool 改变 |
| 负功率、非有限功率/冷却液温度 | 抛出 RangeError |

证据：[linearity-v2.json](reports/linearity-v2.json)；测试：[linearity.test.ts](web/linearity.test.ts)。Float16 POD 基底只在加载时解码；输出场为 Float32，不能宣称其逐位满足任意实数的精确线性运算。

## 实际运行的检查

在 Windows、Intel Core Ultra 7 265、Node 22.23.3、pnpm 12.11.2、Python 3.12.10 上执行：

```text
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm verify
pnpm verify:linearity
python scripts/audit_v2.py
```

- TypeScript 严格检查通过；Vitest **30/30**（保留原 24 项，新增 6 项）。
- Python/TypeScript 最大相对差 1.314e-11。
- 本次重测标量推理 p95 0.0302 ms，标量加 8,192 点场 p95 0.1262 ms。此为本机 Node 测量，不能作为手机浏览器保证。
- 标量模型 216,323 字节；三项模型资源合计 509,168 字节。
- 未重跑训练、未改变最终模型、未降低误差或尺寸验收阈值。

独立审计只需 `requirements-lock.txt` 中已固定的 Python 依赖。上述 Python 命令应在已安装依赖的环境运行。完整从求解到训练的复现仍使用 `python scripts/reproduce.py`；只验证交付件无需重新训练。

## 可直接读取的网格数据

`data/mesh-l3-quarter.npz` 包含实际 L3 四分之一 FEM 网格：24,897 个节点、21,648 个 Q1 六面体单元，默认参数下的毫米坐标、八节点连通表、单元材料层、顶部热流/底部 Robin 节点，以及每个节点的层编号和层内 eta 坐标。连通表采用张量积 dz/dy/dx 顺序；转换为 VTK 顺序使用 `[0,1,3,2,4,5,7,6]`。

所有 500 组样本使用同一拓扑；通过样本的层厚，将 `node_z_layer` 与 `node_z_eta` 转换成物理 z，x/y 保持不变。可运行 `python scripts/export_mesh.py` 重建网格文件。导出验证所有节点均被引用、单元体积为正，总体积与默认几何的四分之一体积一致（705.645 mm³）。详情见 `reports/mesh-export-v2.json`。该导出不改变求解器、原始 500 组数据或代理模型。
