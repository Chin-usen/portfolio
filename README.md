# portfolio

结构设计与多物理场仿真工程师的个人作品集网站。
Personal portfolio of a mechanical design & multiphysics simulation engineer.

**Live:** https://chin-usen.pages.dev （v1.0 上线后可用 / available from v1.0）

## 内容 / What's inside

- **Work** — 职业项目案例（功率模块、车载光学）
- **Lab Bench · 实验台** — 自主项目：可交互 3D 拆解（零件高亮与说明）与参数化仿真（滑块实时驱动结果）
- 中文 / English

## 技术 / Stack

Astro · TypeScript · Three.js · GSAP · Cloudflare Pages.
仿真数据由开源求解器离线计算（CadQuery、FEniCSx/Elmer、OpenFOAM），网页端用代理模型实时求值。
